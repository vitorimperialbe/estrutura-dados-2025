# 📚 Estrutura de Dados 2025 — Java

Repositório com exercícios e implementações práticas desenvolvidos durante a disciplina de **Estrutura de Dados** na **FATEC Ipiranga**, ao longo de 2025.

---

## 🛠️ Tecnologias

- **Java** (Orientação a Objetos)
- Git e GitHub para versionamento colaborativo

---

## 📂 Conteúdo

| Tópico | Descrição |
|---|---|
| **Operadores Java** | Exercícios com operadores aritméticos, relacionais e lógicos |
| **Jogo da Velha** | Implementação completa com lógica de jogo, toString e testes |
| **Lista Ligada (Simples)** | Estrutura de dados com nós encadeados e operações básicas |
| **Lista Duplamente Ligada** | Encadeamento bidirecional com inserção e remoção |
| **Filas** | Implementação de fila com variações de listas |
| **Interface Comparable** | Ordenação e comparação de objetos em Java |
| **Árvore Binária** | Inserção recursiva e percurso em árvore binária |

---

## 📖 Sobre

Os exercícios foram desenvolvidos aula a aula, com foco em compreender as estruturas de dados fundamentais utilizadas no desenvolvimento de software. Cada pasta corresponde a uma aula ou tema específico trabalhado durante o semestre.
